# Beamlet

> Light on device, smart on the mesh.

***WIP***

## Build

```bash
# Development shell
nix develop

# Package
mix local.hex
mix local.rebar
mix deps.get
mix deps.update --all

# Format
mix format

# Compile
mix compile

# Test
mix test
```
